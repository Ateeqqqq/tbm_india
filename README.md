# The Buzz Media React

Converted from the standalone HTML site to a Vite + React project.

## Run

```bash
npm install
npm run dev
```

The site uses the Animate UI BubbleBackground pattern implemented as a React component with Motion, customized to The Buzz Media orange/blue palette.


## New service detail pages
Added four dedicated detail routes:
- #performance-marketing
- #seo
- #digital-marketing
- #app-development

Each page uses the shared premium service-detail system: Lenis smooth scrolling, scroll-triggered reveal/stagger, matte card interactions, service dropdown navigation, FAQ accordion, consultation form, CTA, and TBM footer.
